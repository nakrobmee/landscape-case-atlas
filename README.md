# Landscape Case Atlas

เว็บไซต์คลังกรณีศึกษางานภูมิสถาปัตยกรรมทั่วโลก มี 3 หน้า:
- `index.html` — แผนที่ลูกโลก กดหมุดเพื่อดูการ์ดโครงการ
- `cases.html` — ตารางกรณีศึกษา เรียงตามปี/พื้นที่/งานวิจัย ฯลฯ กรองตามภูมิภาค ประเทศ ประเภทงาน ดาวน์โหลด CSV ได้
- `project.html?id=…` — หน้ารายละเอียด: ผัง แบบ ภาพ งานวิจัย บันทึกการอัปเดต

## เปิดดูเว็บไซต์
รัน `python3 -m http.server 8765` ในโฟลเดอร์นี้ แล้วเปิด http://localhost:8765

## งานตั้งเวลา (Claude)
| งาน | เวลา | ทำอะไร |
|---|---|---|
| `weekly-landscape-case-studies` | จันทร์–ศุกร์ 09:05 | อ่าน `inbox.md` ก่อน → ค้นงานใหม่ทั่วโลกจากสื่อออกแบบ + social media (Reddit, Instagram, Facebook, LinkedIn, YouTube) → เพิ่มวันละ 5 โครงการ |
| `monthly-landscape-case-updates` | วันที่ 1 ของเดือน 13:00 | ตรวจทานงานเดิมสูงสุด 30 โครงการ/เดือน: งานวิจัยใหม่ ภาพปัจจุบัน ข่าว/เฟสใหม่ ลบภาพเสีย |

## ส่งลิงก์ที่น่าสนใจ
วางลิงก์ลงใน `inbox.md` ใต้หัวข้อ "รอดำเนินการ" (บรรทัดละลิงก์ ใส่โน้ตหลัง `|` ได้)
งานรายวันจะหยิบไปทำก่อน แล้วย้ายลงหัวข้อ "ดำเนินการแล้ว" พร้อมผลลัพธ์ (เพิ่มใหม่ / อัปเดต / ข้าม + เหตุผล)

## โครงสร้าง
- `data/projects.json` — ข้อมูลต้นฉบับ (แก้ไขที่นี่)
- `tools/build.py` — ตรวจข้อมูลและสร้าง `data/projects.js` (+ ไฟล์ KML/CSV ใน `exports/`)
- `assets/` — สไตล์ ฟังก์ชันร่วม และค่าแผนที่ (Mapbox token ใน `config.js`)
- ฟิลด์ที่งานรายเดือนเพิ่ม: `last_reviewed`, `updated_date`, `updates` [{date, note_th}]; ภาพมี `year` ได้
